# 실루의 그림자 재단소

3명의 손님을 만나 실루의 힌트를 해석하고 그림자를 다듬는 모바일 웹게임.

## 실행과 배포

`dist/index.html`을 더블클릭해서 로컬에서 플레이할 수 있다. Node/npm 설치 없이 동작하며 외부 API 및 서버 DB가 없다. 로컬에서는 `dist`를 정적 HTTP 서버로 제공할 수도 있다. 예를 들어 VS Code Live Server를 사용하거나 Python이 설치된 경우 `python -m http.server 8080 --directory dist`를 실행한다. 빌드 단계가 없는 경량 정적 구성으로 `dist` 전체가 배포 결과물이다. GitHub Pages, Vercel, Netlify의 정적 출력 폴더를 `dist`로 지정할 수 있다. Netlify Drop의 경우 압축을 푼 뒤 `dist` 폴더를 업로드한다.

## 플레이 구조

START → 손님 → 실루의 해석 → 재단 → 평가 → 전달 → 다음 손님 → 마감. 재단은 지우기, 펼치기는 작은 부분 더하기로 구현된다. Canvas Pointer Events 및 `touch-action: none`은 작업 영역에만 적용된다. Undo와 Reset은 전체 스트로크 이력을 재현한다.

## 판정 방식

- CLIENT FIT: 사례별 추천 영역과 실제 변경된 픽셀의 일치율. 자신감은 어깨 확장 및 밑단 정리, 편안함은 날카로운 외곽 제거, 용기는 위쪽 단일 포인트.
- ORIGINALITY: 총 제거량, 중앙 특징 영역 훼손, 분리된 그림자 조각, 전체 변경량.
- SILU TASTE: 좌우 비대칭, 적정 변경량, 균형, 작업의 연속성.
- PLAYFUL POINT: 변경된 작은 구역 수와 작업량, 포인트의 과잉 및 분리 여부.

정답 선을 강제하지 않고 실제 결과의 픽셀 마스크를 평가한다. 노트의 디자인 원칙을 휴리스틱으로 번역한 프로토타입이다. 실루는 작업 중 변경량과 영역에 따라 표정과 대사를 바꾼다.

## 이미지

`dist/assets/Untitled.jpg`~`Untitled5.jpg`: 사용자가 직접 제공한 원본 렌더의 900px 경량 JPEG. AI 재생성 및 실루 재디자인 없음. 손님과 그림자는 벡터/Canvas로 구현.

`dist/assets/notes/01.jpg`~`06.jpg`: 사용자가 제공한 실루의 작업 노트 원본 6장. 상단의 작업 노트 버튼으로 언제든 열람할 수 있으며, 목차·이전/다음·확대 기능을 지원한다. 노트를 열거나 닫아도 진행 중인 재단 및 Undo 이력은 그대로 유지된다. 노트 이미지는 펼칠 때 순차 로딩된다.

노트를 열면 보라색 금박 책 표지가 약 1초 동안 펼쳐진 뒤 원본 노트 화면이 나타난다. 기기의 모션 감소 설정이 켜져 있으면 애니메이션을 생략한다.

## 모바일 테스트

Chrome 개발자 도구에서 390×844, 360×640, 태블릿·데스크톱 크기를 확인하고 터치 입력 에뮬레이션으로 재단한다. 기기에서는 실제 HTTPS 배포 URL을 Android Chrome과 iPhone Safari로 접속해 한 손가락 재단, 스크롤 억제, Undo/Reset, 완료 및 다음 손님을 확인한다.

## QR

공개 HTTPS 배포 URL 확정 후 URL QR을 흰 여백을 포함한 PNG 또는 SVG로 출력한다. 배포 주소가 바뀌면 새 QR을 생성한다. 로그인 없이 새 브라우저에서 접속 가능한지 확인 후 전시물에 사용한다.

## 확장

추가 손님 사례, 재단 효과음, 실루 애니메이션, 추가 재단 도구, 결과 엽서 다운로드.
